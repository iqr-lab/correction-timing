Example data that can be used to generate results using the codes. 800 trajectories (50 data points for 4 shapes and 4 targets) with corrections and 800 trajectories without corrections to match with real data. Saved as config/example_data.pkl

Adding correction timing to pre-planned trajectories:
python3 rescaled_correction_timing.py
Saved as config/example_data_rescaled.pkl

To extract features from the data, run:
python3 extract_features.py -c True -tr 0.7
-c True for corrected data, False for uncorrected data (run -tr = 1 for uncorrected data)
-tr 0.n for the timing ratio of the data 
Saved in features/

To get the sample of data points that is the most informative, run
cal_entropy.py -s shape 
Saved in dropping_blocks/samples/
To get the indices corresponding to the ones in simulator that is the most diverse across simulators. The indices then are used pick the poses to drop blocks in real life, so that we can compare real life data with simulator data to pick the best simulator for generating more ground truth data.

To show which simulator has the closest results compared to real life:
python3 pick_sim.py -s shape

To get the gmms for ground truth derived from poses of simulator data from simulators that are the closest to the real life, run
best_sim_gmm.py -s shape
Saved in goal_infer_files/gmms/ground_truth/

To generate split data by indices for training(60%)/validating(10%)/testing(30%) for both when and where and combined model, run
python3 split_data.py -tr 0.7(0.7-1 timing_ratio) -split 0.6(how much training set is) -tg 0 (0-3 target) -s shape -r 0 (0-9 different splits)
Can run bash tasklist.sh to include all different conditions.
Saved in splits/

To train model to infer where people leave the gripper based on where they grasp it, run:
python3 where_model.py -s 0.6(split) -tr 0.7 -r 0
Can run bash tasklist_where_infer.sh to include all different conditions.
Saved in goal_infer_files/where_infer/

To get the gmm models of p(where people leave the gripper/goal), run:
python3 gmm_training.py -tr timing ratio -s 0.6 -r 0 
Can run bash tasklist_gmm.sh to include all different conditions.
Saved in goal_infer_files/gmms/leaving/

To train transformer based on all features to infer when a correction happens, run 
python3 transformer_training_all_feature.py -s 0.6 -tr {tr} -r {i} 
Can run bash tasklist_transformer.sh to include all different conditions.
Saved in goal_infer_files/when_weights/

To train transformer based on Boltzmann feature to infer when a correction happens, run 
python3 transformer_bol.py -s 0.6 -tr {tr} -r {i} 
Can run bash tasklist_transformer_bol.sh to include all different conditions.
Saved in goal_infer_files/when_weights_bol/

To train transformer based on ablation test (one less feature at a time) run 
python3 transformer_ablation.py -s 0.6 -tr {tr} -r {i} -d {feature index to exclude}
Can run bash tasklist_transformer_ablation.sh to include all different conditions.
Saved in goal_infer_files/when_weights_ablation/

To extract features based on different sampled goals, run 
python3 extract_features_xysampling.py -tr (0.7-1) -x x_offset -y y_offset
Can run python3 generate_tasklist.py to generate task list files to include all different conditions (change the sample space size and definition based on needs), and run bash tasklist_feature_offset.sh
Saved in features/sampled/

To get the KLD between ground truth vs PWHEN, PWHERE and PCOMBINED, run python3 goal_infer.py -s 0.6 -tr {tr} -sh {shape} -tg {int(target)} -r {int(rep)} -t {t}python3 goal_infer.py -s 0.6 -tr {tr} -sh {shape} -tg {int(target)} -r {int(rep)} -t {t}
t = "grasp" for using where people grasp the gripper to infer release position to infer goal; t = "release" for using where people release the gripper to infer goal.
Can run bash tasklist_goal_infer.sh to include all conditions.
Data saved in results/KLDs or results/KLDs_leaving

To see the effect of weight alpha for goal inference, run python3 goal_infer_alpha.py -s 0.6 -tr {tr} -sh {shape} -tg {int(target)} -r {int(rep)} -a {alpha} -t grasp
Can run bash tasklist_goal_infer_alpha.sh to include all conditions.
Data saved in results/KLDs_alpha
