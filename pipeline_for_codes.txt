Example data that can be used to generate results using the codes. 100 trajectories with corrections and 100 trajectories without corrections.

To extract features from the data, run:
python3 extract_features.py -c True -tr 0.7
-c True for corrected data, False for uncorrected data (run -tr = 1 for uncorrected data)
-tr 0.n for the timing ratio of the data 

To get the sample of data points that is the most informative, run
cal_entropy.py -s shape
To get the indices corresponding to the ones in simulator that is the most diverse across simulators. The indices then are used pick the poses to drop blocks in real life, so that we can compare real life data with simulator data to pick the best simulator for generating more ground truth data.

To show which simulator has the closest results compared to real life:
python3 pick_sim.py -s shape

To get the gmms for ground truth derived from poses of simulator data from simulators that are the closest to the real life, run
best_sim_gmm.py -s shape
